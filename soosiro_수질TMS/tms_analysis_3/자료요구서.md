## A. 측정소 정보

### A-1. 측정소 좌표·주소·코드 ★★★ (가장 먼저)
- **왜**: 지금 기상지점·유량관측소·상류 사업장 연결이 모두 '이름·행정구역 추정'이다. 좌표가 있으면 `tools/link_stations.py` 가 거리로 자동 연결해 40·41·42번 결과의 신뢰도가 크게 오른다.
- **출처**: 물환경정보시스템(water.nier.go.kr) → 측정망 정보 → 수질자동측정망 측정소 현황(주소·위경도). 화면에 없으면 국립환경과학원 물환경정보시스템 담당에 요청.
  수질자동측정망 Open API(아래 C-1)의 응답에 측정소 ID(S0xxxx)가 있으므로 같이 받아 둔다.
- **양식**: `templates/station_info_request.csv` (77개 측정소 이름이 채워져 있음)

| 열 | 내용 | 예 |
|---|---|---|
| basin, station | 수정 금지 | 한강, 가평 |
| 측정소코드 | 물환경정보시스템 측정소 ID | S01001 |
| lat, lon | 위도·경도(십진수, WGS84) | 37.8312, 127.5101 |
| 주소, 하천명, 중권역 | 참고 | 경기도 가평군 …, 북한강, 북한강하류 |

- **받은 뒤**: lat·lon 을 `data/meta/stations.csv` 의 같은 측정소 행에 붙여 넣기(엑셀) → `python tools/link_stations.py` → `--apply`.

### A-2. 하천 줄기·순서 ★★
- 현재 `stations.csv` 의 stem(줄기)·stem_order(상류→하류 순서)는 5개 줄기를 지명으로 추정했다(한강 남한강→본류, 북한강, 금강·낙동강·영산강 본류).
- 좌표와 하천도로 확인하고, 지류(경안천·신천 등)는 `stem` 에 '경안천' 처럼 따로 적으면 32번이 자동으로 종단 분석한다.

### A-3. 측정소 상류 TMS 사업장 ★★★
- **왜**: 42번(방류수 → 하천 영향)의 핵심. 현재 한강 5곳(경안천·복하천·청미천·신천·포천)만 행정구역 기준 가설로 연결.
- **방법**: 표준유역(또는 중권역) 경계 GIS(물환경정보시스템·WAMIS 제공) + TMS 사업장 좌표(`../tms_analysis_2/data/tms_location_geocoded.csv`) 로 '측정소 상류 유역 안 사업장'을 고른다.
- **양식**: `stations.csv` 의 `upstream_tms` 에 사업장명을 `;` 로 구분(이름은 tms_analysis_2 의 `site` 와 같게).

- **구역 경계 파일(43번 구역 설정)**: 물환경정보시스템 또는 WAMIS 에서 표준유역(또는 수질오염총량 단위유역) 경계 shp 를 받아,
  QGIS 에서 **GeoJSON·EPSG:4326** 으로 저장해 `data/raw/gis/` 에 넣는다(geopandas 가 있으면 shp 그대로도 가능).
  → `python tools/assign_upstream.py --code-col <구역코드 열> --auto` (절차: RESEARCH_REVIEW.md 1.6)

### A-4. 목표기준 등급 ★★
- 「물환경 목표기준」(중권역별 TOC·TP 목표 등급)을 측정소가 속한 중권역에 맞춰 `stations.csv` 의 `target_grade` 에 Ia·Ib·II·III… 로 적는다. 비우면 II 등급을 가정한다(12번).

## B. 수문·기상

### B-1. 기상 ASOS 일자료 ★★★
- **왜**: 40번(강우 반응·분포시차·기온-수온 민감도). 지금은 경기권 15지점이라 한강·미호강만 계산된다.
- **API(권장)**: 공공데이터포털 「기상청_지상(종관, ASOS) 일자료 조회서비스」 활용신청 → 일반 인증키(Decoding)를 `data/api_keys.env` 의 `DATA_GO_KR_KEY=` 에.
  - 요청: `http://apis.data.go.kr/1360000/AsosDalyInfoService/getWthrDataList?serviceKey=…&dataType=JSON&dataCd=ASOS&dateCd=DAY&startDt=20240101&endDt=20241231&stnIds=133&numOfRows=999`
  - 응답 주요 필드: `tm`(날짜), `stnId`, `stnNm`, `avgTa`, `minTa`, `maxTa`, `sumRn`(일강수, 비 없으면 빈칸)
  - 실행: `python collectors/collect_kma_asos_daily.py --test` → `python collectors/collect_kma_asos_daily.py --start 2024-01-01 --end 2025-12-31`
  - 대상 지점: `stations.csv` 의 weather_stn(현재 추정 31개 지점: 서울108·춘천101·대전133·청주131·대구143·광주156·안동136·진주192 …)
- **수동(대안)**: 기상자료개방포털(data.kma.go.kr) → 지상 → 종관기상관측(ASOS) → 일자료 CSV(요소: 평균·최저·최고기온, 일강수량) → `data/raw/kma_asos/` 에 넣으면 기존 매핑 `kma_asos_daily.json` 이 그대로 읽는다.
- **선택**: 방재기상관측(AWS) 일자료 — 측정소 가까운 강수가 필요할 때(같은 매핑에 inputs 만 추가).

### B-2. 하천 유량 일자료 ★★★
- **왜**: 41번(C–Q 진단·부하량·부하지속곡선), 42번(TMS 기여율). 지금은 한강 11개 측정소만 홍수통제소 관측소와 연결.
- **API**: 한강홍수통제소 Open API(hrfco.go.kr, 전국 수위·유량 관측소 포함) — 키를 `HRFCO_KEY=` 에.
  - `python collectors/collect_hrfco.py --test` → `python collectors/collect_hrfco.py --region all --start 2024-01-01 --end 2025-12-31` (**국내 인터넷에서만 접속됨**)
  - 결과 `data/raw/hrfco/` → `python 02_ingest_aux.py` → 좌표(A-1)가 있으면 `tools/link_stations.py` 로 측정소 5 km 이내 관측소 자동 연결
- **보완**: WAMIS(wamis.go.kr) Open API 유량 일자료 — `collectors/collect_wamis_flow.py --test` 로 형식 확인 후 매핑(작업안내서 3-C).
- **양식(표준 flow_daily)**: obscd, obs_name, date, wl_m(수위 m), flow_cms(유량 m³/s)

### B-3. 댐 방류량 ★★
- 충주·의암호·화천·대청호·용담호·안동댐하류·옥정호·주암호 등은 댐 운영이 수온·탁도·Chl-a 를 지배한다(40번 기온-수온 민감도가 낮은 곳: 충주 0.43, 화천 0.56).
- 출처: K-water 물정보포털(MyWater) 댐 운영 자료 또는 WAMIS 댐 일자료. 열: 댐코드, 날짜, 방류량(m³/s), 저수위(EL.m), 유입량.
- 붙이기: `data/inbox/dam/` → `tools/make_mapping.py … --target flow_daily` (obscd 에 'DAM_'+코드) → stations.csv 에 `dam_obscd` 열을 새로 만들어 연결.

### B-4. 보 운영 정보 ★
- 낙동강·금강·영산강 보 구간 측정소(칠곡·강창·고령·적포·칠서·남면·공주·부여·나주·서창교 등)의 조류 해석에 필요. 출처: K-water 보 운영(개방 기간, 관리수위).

## C. 수질 추가 자료

### C-1. 자동측정망 2026년 이후 ★★★
- **왜**: 현재 2년이라 추세(21)·극값(35)·예측(37)이 '예비'다. 3년째부터 결론이 단단해진다.
- **수동(권장, 가장 확실)**: 물환경정보시스템 → 수질자동측정망 → 시간자료 엑셀 → `data/raw/nier_auto_xlsx/2026_국가수질자동측정망/<권역>/` (파일명 그대로) → `python run_all.py full`
- **API**: 공공데이터포털 「국립환경과학원_수질 DB」(데이터 15081073) 활용신청
  - 요청: `http://apis.data.go.kr/1480523/WaterQualityService/getRealTimeWaterQualityList?serviceKey=…&resultType=json&siteId=S01023&startDate=20260101000000&endDate=20260131235959&numOfRows=1000&pageNo=1`
  - 응답: `MSR_DATE`, `SITE_ID`, `SITE_NAME`, 항목 코드(M02 수온, M03 pH, M04 EC, M05 DO, M06 TOC, M27 TN, M28 TP, M29 Chl-a 등 — **공개 예제 기준 추정, `--test` 로 확인**)
  - 실행: `python collectors/collect_nier_api.py --test` → `--probe`(측정소 ID 목록 자동 탐색) → `--start … --end …`
  - 붙이기: `python ingest/mapper.py ingest/mappings/nier_api_hourly.json --dry-run` → 확인 후 실행(시간→일 요약해 river_daily 에 합침)
  - 주의: 확정자료 공개가 수개월 늦을 수 있다. 대량은 엑셀이 빠르다.

### C-2. 수질측정망(채수 분석) ★★
- 같은 지점(또는 인근)의 실험실 분석값으로 자동측정값의 편향을 확인(특히 TP 의 ND 문제 — 10번: 용담호 ND 25%).
- 열: 측정소, 채수일, TOC, TN, TP, Chl-a, … (단위 mg/L). 표준 양식이 없으므로 `core/schema.py` 에 `river_grab` 양식을 추가해 붙인다(작업안내서 3-E 와 같은 방식, Claude 에게 요청).

### C-3. 조류경보 남조류 세포수 ★★
- 34번의 고농도 기준(Chl-a 25 mg/㎥)을 실제 경보 단계(남조류 세포수)와 맞추기 위함. 출처: 물환경정보시스템 조류 정보. 열: 지점, 채수일, 남조류 세포수(cells/mL), Chl-a, 경보 단계.

### C-4. 총량측정망 ★★
- 유량과 수질을 함께 재는 유일한 측정망(8일 간격). 41번 부하 계산의 검증·자동측정소-유량 연결 확인에 사용.

### C-5. 측정소 운영 이력 ★★
- 10번(고정값: 동복호 EC 32%)·25번(계단형 변화)이 센서 문제인지 실제 변화인지 가리는 데 필요. 열: 측정소, 날짜, 항목, 내용(교정·교체·고장·정전), 결측 사유.
