# 34. 조류 고농도 위험과 조기경보 가능성

- 스크립트: `34_bloom_risk.py`  ·  단계: 심화
- 실행 시각: 2026-11-05 06:02

## 목적

Chl-a 고농도일(절대 기준과 측정소별 상위 10%)이 언제·어디서 잦은지, 어떤 조건에서 확률이 오르는지(오즈비), 그리고 오늘 자료로 3일 뒤 고농도를 얼마나 맞힐 수 있는지(조기경보 성능)를 평가한다.

## 핵심 결과

- Chl-a ≥ 25 일이 10% 넘는 측정소 33곳 — 최다 나주 71%, 청암 63%, 용봉 56%
- 한강 3일 앞 조류 고농도 예측 AUC 0.90 (오늘 Chl-a 만 0.87, 월 기후값 0.67) — 수질·수온 정보가 경보 정확도를 높임
- 낙동강 3일 앞 조류 고농도 예측 AUC 0.86 (오늘 Chl-a 만 0.89, 월 기후값 0.74) — 오늘 Chl-a 지속성만으로도 대부분 설명
- 금강 3일 앞 조류 고농도 예측 AUC 0.86 (오늘 Chl-a 만 0.89, 월 기후값 0.76) — 오늘 Chl-a 지속성만으로도 대부분 설명
- 영산강 3일 앞 조류 고농도 예측 AUC 0.85 (오늘 Chl-a 만 0.87, 월 기후값 0.59) — 오늘 Chl-a 지속성만으로도 대부분 설명
