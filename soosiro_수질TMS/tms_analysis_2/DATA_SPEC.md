# 자료 수집 명세서 (DATA_SPEC v2, 2026-11-04)

앞으로의 분석(21~23번과 05·18번 재실행)에 필요한 자료의 **파일명, 열 이름, 단위, 출처**를 미리 정한 문서입니다.
`templates/` 폴더에 처리장 이름·시군·주소를 미리 채운 양식이 있습니다. 빈칸만 채워 `data/` 폴더에 같은 이름으로 넣으면 됩니다.

공통 규칙
- 파일 형식: CSV(UTF-8 또는 엑셀 저장 시 'CSV UTF-8'). 기상청 원본은 내려받은 그대로(cp949) 넣어도 됩니다.
- `site` 값은 TMS 사업장명과 **글자 하나까지 같아야** 합니다(예: `고양난지하수`, `[폐쇄]` 표시는 빼고). 양식의 이름을 그대로 쓰세요.
- 날짜: `YYYY-MM-DD`. 숫자: 쉼표 없이. 모르는 칸은 비워 둡니다(0을 넣지 마세요).
- 기간: TMS 자료와 같은 **2024-01-01 ~ 최신(현재 2026-06-30)**.

## B. 기상자료 (필수)

### B-1. `data/weather/` — 기상청 일자료 (파일 여러 개 가능)
- 출처: 기상청 기상자료개방포털(data.kma.go.kr) → 데이터 → 기상관측 → 지상
  - **종관기상관측(ASOS) 일자료**: 경기도 지점 전부 + 서울·인천·강원 인접 지점(경계 처리장용)
  - **방재기상관측(AWS) 일자료**: 경기도 지점 전부 — 처리장 가까운 강수가 중요하므로 AWS가 핵심
- 요소: **평균기온, 최저기온, 최고기온, 일강수량** (다른 요소는 있어도 무시)
- 기간: 2024-01-01 ~ 2026-06-30(이후 TMS가 늘면 함께 연장)
- 형식: 내려받은 CSV 그대로. 기간·지점 제한 때문에 여러 파일로 받아도 폴더에 모두 넣으면 자동으로 합칩니다.
- 코드가 찾는 열(이름에 아래 글자가 포함되면 인식):

| 표준 변수 | 원본 열 이름 예 | 단위 | 비고 |
|---|---|---|---|
| stn | `지점` | – | 지점번호 |
| stn_name | `지점명` | – | |
| date | `일시` | YYYY-MM-DD | |
| rain_mm | `일강수량(mm)` | mm | 빈칸 = 0(비 안 옴)으로 처리 |
| ta_mean | `평균기온(°C)` | ℃ | |
| ta_min | `최저기온(°C)` | ℃ | '시각' 열은 자동 제외 |
| ta_max | `최고기온(°C)` | ℃ | |

### B-2. `data/weather_stations.csv` — 지점정보
- 출처: 기상자료개방포털 → 메타데이터 → 지점정보(ASOS, AWS 각각 받아 한 파일로 합치거나 둘 다 붙여 넣기)
- 필요한 열: `지점`, `지점명`, `지점주소`, `위도`, `경도` (원본 열 이름 그대로 OK)
- 지점 이전으로 같은 지점이 여러 행이면 마지막 행을 씁니다.

## C. 시설·지역 정보

### C-1. `data/site_region.csv` — 방류수 수질기준 지역 (필수)
양식: `templates/site_region.csv` (261개 사업장, 하수 169개가 위쪽)

| 열 | 내용 | 예 |
|---|---|---|
| site | 사업장명(수정 금지) | 가평하수 |
| code, site_type, sigun | 참고용(수정 불필요) | 41A0651, 하수, 가평군 |
| **region** | 「하수도법 시행규칙」 방류수 수질기준의 지역 구분 | `I` / `II` / `III` / `IV` (1~4, Ⅰ~Ⅳ도 인식) |
| std_TOC, std_SS, std_TN, std_TP | (선택) 특례·별도 기준이 있으면 그 값(mg/L) | 비워 두면 지역 기준 적용 |
| note | 근거·메모 | 특례 적용 등 |

- 하수처리장 169곳만 먼저 채워도 됩니다. TN 기준 초과가 많았던 **양주신천·동두천**은 특례·판정 방식을 note에 꼭 적어 주세요.
- 주의: config.py 의 기준값 표(I~IV)도 현행 법령과 한 번 대조해 주세요.

### C-2. `data/site_coords.csv` — 처리장 좌표 (선택)
양식: `templates/site_coords.csv` (주소가 채워져 있음)
- 열: `site`, `lat`(위도, 십진수), `lon`(경도, 십진수) — `sigun`, `address`는 참고용
- 방법: 주소를 지오코딩(브이월드·카카오 주소검색 등)하거나 공공데이터의 시설 좌표 사용
- 없으면 처리장과 같은 시군의 기상지점 평균을 씁니다(충분히 쓸 만함).

### C-3. `data/site_facility.csv` — 시설 제원 (권장)
양식: `templates/site_facility.csv` (하수 169곳)

| 열 | 내용 | 단위·형식 |
|---|---|---|
| capacity_m3d | 시설용량(증설 포함 합계) | m³/일 |
