# 33. 조류(Chl-a)를 움직이는 요인

- 스크립트: `33_chla_drivers.py`  ·  단계: 심화
- 실행 시각: 2026-11-05 06:02

## 목적

수온·영양염·탁도·계절 중 무엇이 Chl-a 를 가장 잘 설명하는지 수계별로 비선형 모형으로 평가하고(순열 중요도), TP 가 높을 때 Chl-a 가 '최대 어디까지' 오를 수 있는지 분위회귀(90% 분위)로 추정한다.

## 핵심 결과

- 금강 Chl-a [통합] 주요 요인: 수온 > 최근3일 최대탁도 (월 블록 교차검증 R²=0.55)
- 낙동강 Chl-a [통합] 주요 요인: 수온 > 최근3일 최대탁도 (월 블록 교차검증 R²=0.43)
- 영산강 Chl-a [통합] 주요 요인: EC > 최근3일 최대탁도 (월 블록 교차검증 R²=0.58)
- 한강 Chl-a [통합] 주요 요인: EC > 계절(cos) (월 블록 교차검증 R²=0.41)
- 금강 Chl-a [측정소내] 주요 요인: 수온 > 계절(sin) (월 블록 교차검증 R²=0.43)
- 낙동강 Chl-a [측정소내] 주요 요인: 수온 > TP (월 블록 교차검증 R²=0.26)
- 영산강 Chl-a [측정소내] 주요 요인: EC > 수온 (월 블록 교차검증 R²=0.33)
- 한강 Chl-a [측정소내] 주요 요인: 계절(cos) > 수온 (월 블록 교차검증 R²=0.22)
- 금강 Chl-a 의 TP 탄력성: 중앙 0.15 → 상위10% 0.32 (고농도일수록 인 영향 큼)
- 낙동강 Chl-a 의 TP 탄력성: 중앙 -0.02 → 상위10% -0.03 (고농도에서 인 영향 작음 = 다른 제한 요인)
- 영산강 Chl-a 의 TP 탄력성: 중앙 0.44 → 상위10% 0.48 (고농도일수록 인 영향 큼)
- 한강 Chl-a 의 TP 탄력성: 중앙 -0.06 → 상위10% 0.27 (고농도일수록 인 영향 큼)

**입력 자료**: 행 수 47731 · 기간 2024-01-01 ~ 2025-12-31 · 측정소 수 77
