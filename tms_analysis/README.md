# TMS 일자료 분석 패키지 (기상자료 결합 전 단계)

경기도 TMS 일자료만으로 바로 얻을 수 있는 인사이트를 분석법별 스크립트로 나눠 둔 패키지입니다.
각 스크립트는 독립 실행되며, 결과는 `results/<번호_이름>/summary.md`(Claude가 읽는 요약) + CSV + 그림으로 저장됩니다.

## 1. 폴더 준비

```
tms_analysis/
├─ data/
│   ├─ tms_all_raw.csv          ← 크롤링 원자료(필수, 파일명 그대로)
│   ├─ site_list_2024Q1.csv     ← 사업장 코드(선택)
│   ├─ tms_location.csv         ← 사업소,소재지(선택: 시군 분석에 사용)
│   ├─ failed.log               ← 수집 실패 로그(선택)
│   └─ site_region.csv          ← site,region(선택: 방류수 기준 지역 I~IV)
├─ config.py   common.py
├─ 01_preprocess.py … 19_lead_lag_granger.py
├─ 20_build_digest.py   run_all.py
└─ requirements.txt
```

- `tms_location.csv`는 지난번 `TMS 사업장 소재지` 파일을 이 이름으로 저장하면 됩니다.
- 파일명이 다르면 `config.py` 맨 위 경로만 고치세요.

## 2. 설치(VS Code 터미널)

```
pip install -r requirements.txt
```

`ruptures`, `pymannkendall`, `tslearn`은 없어도 됩니다(해당 부분만 대체 방법으로 계산하거나 건너뜀).

## 3. 실행 순서

1. **`01_preprocess.py`를 가장 먼저 1회** 실행 → `work/tms_clean.pkl` 생성
2. 02~19는 순서와 무관하게 하나씩 실행해도 됩니다(모두 01의 산출물만 사용)
3. 다 끝나면 `20_build_digest.py` 실행 → `results/00_DIGEST_for_Claude.md`와 `results_for_claude.zip` 생성
4. 한 번에 돌리려면 `python run_all.py` (특정 번호만: `python run_all.py 04 06 11`)

## 4. 분석 목록

| 번호 | 분석 | 얻는 것 |
|---|---|---|
| 01 | 전처리·데이터셋 개요 | 범위, 중복, 0값, 유량 역산 가능성, 방류구별 보유율 |
| 02 | 자료품질 진단 | 결측·고정값·해상도·급변, 방류구 품질점수(A~D), 시스템 중단일 |
| 03 | 기술통계·분포 | 유형·규모·시군별 수준, 변동계수, TN/TP·TOC/TN 비 |
| 04 | 역산 유량 분석 | 첨두계수, 천장(용량 제한) 의심, 습윤기 민감도 예비순위, 광역 고유량일 |
| 05 | 기준 대비 여유도 | 기준 대비 비율, 초과확률, 신뢰도계수(CoR) |

| 08 | 추세(계절 MK) | Sen 기울기, 같은 달 연도 비교 |
| 09 | 변화점 탐지 | 수준이 계단처럼 바뀐 시점(공정 변경·센서 교체 후보) |

| 17 | 다중 방류구 비교 | 방류구 역할(병렬 계열, 강우시 계통 후보) |

## 6. 꼭 확인할 설정(`config.py`)

- `FOCUS_TYPES`: 기본은 하수처리시설만. 전체는 `None`
- `DISCHARGE_STANDARDS`, `DEFAULT_REGION`: 방류수 기준값과 지역 구분은 현행 하수도법 시행규칙으로 확인
- `HOLIDAYS`, `MAJOR_HOLIDAYS`: 공휴일 목록 확인
- `ZERO_AS_MISSING`: 농도 0을 결측으로 볼지
- 배출량 단위는 kg/일로 가정(유량 = 배출량 ÷ 농도 × 1000, m3/일)

## 7. 해석 시 주의

- 유량은 TMS 배출량에서 역산한 값입니다. 방류구로 나간 처리수만 보이며, 월류·우회 유량은 보이지 않습니다.
- 유량을 TN으로 역산하면 Q–TN 관계에 허위상관이 생깁니다. 그래서 11·13·19번은 항목마다 다른 항목으로 역산한 유량을 씁니다.
- 자료 기간이 약 2.5년이라 추세(08)와 극값(18)은 순위 비교용 보조 지표로 보세요.
