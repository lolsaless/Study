# 36. 시계열 기억 길이와 주기

- 스크립트: `36_memory_spectral.py`  ·  단계: 심화
- 실행 시각: 2026-11-05 06:03

## 목적

계절을 뺀 편차가 며칠이나 이어지는지(관성), 우연한 출렁임인지 장기기억인지(DFA), 7일 주기가 배경보다 강한지 본다. 기억이 길면 예측이 쉽고(37번), 7일 주기가 강하면 인위 배출 영향(23번)이다. 호소와 하천의 차이도 드러난다.

## 핵심 결과

- 계절 제거 편차의 기억 길이: 호소가 하천의 1.1배(항목 중앙) — 31일 창으로 계절을 뺀 단기 변동에서는 호소·하천 차이가 작다
- 7일 주기 스펙트럼이 배경의 3배 이상: 7건 — 포천 EC, 신천 EC, 한탄강 EC, 신천 TOC, 성서 EC
- DFA α 중앙 0.67 — 계절 제거 후에도 장기기억(0.5<α<1)이 있어 '독립 표본' 가정 검정은 유의성을 과대평가한다(블록 부트스트랩·측정소 단위 검정 사용 이유)

**입력 자료**: 행 수 47731 · 기간 2024-01-01 ~ 2025-12-31 · 측정소 수 77

- 전체 표: `memory_by_station.csv` (483행)
