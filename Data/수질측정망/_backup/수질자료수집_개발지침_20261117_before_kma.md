> 다른 채팅에서 수집 코드를 새로 만들거나 고칠 때 이 문서를 먼저 읽는다. 최종 갱신 2026-11-17.
> 함께 볼 문서: `수질API_활용가이드.md`(요청·응답 형식), `site_code/수질측정망_지점코드.md`(지점·항목 코드).
> 연구 전체 규칙(폴더 구조·분석·보고)은 프로젝트 지침과 `TMS_연구_진행현황.md`를 따른다.

## 1. 수집 폴더 구조 (맥미니 `~/Documents/GitHub/Study/Data/수질측정망/`)

```
수질측정망/
├── 물환경_수질측정망.py          물환경 수질측정망 수집 코드 (사용자가 이름 변경)
├── 물환경.env                    공공데이터포털 인증키 (밖으로 내보내지 않음)
├── 수질API_활용가이드.md
├── 수질자료수집_개발지침.md       이 문서
├── site_code/                    지점·측정소 코드표
│   ├── 물환경_수질측정망_지점코드_전체.csv   (구분·지점코드·지점명·조사기관·주소·대권역·중권역, 2,218개)
│   ├── 수질자동측정망_측정소코드_전체.csv     (대권역·측정소코드·측정소명, 71개)
│   └── 수질측정망_지점코드.md
├── raw_data/                     API에서 받은 연도별 자료: 2024.csv, 2025.csv, 2026.csv …
├── data/                         가공 결과: all_data.csv, columns.csv, sites_hangang.csv
└── _backup/                      코드 수정 전 사본
```

- 받은 그대로의 단위 파일은 `raw_data/`, 합친 것·설명표·대상 목록은 `data/`, 코드표는 `site_code/`에 둔다. 새 수집 코드도 이 구분을 따른다.
- 코드를 크게 고칠 때는 `_backup/<이름>_<날짜>_before.py`로 먼저 복사한다.

### 물환경_수질측정망.py 사용법과 현황
- 설정(맨 위): `START_YEAR`, `END_YEAR`(None = 올해), `MONTHS`, `BASIN`, `SITE_TYPES`, `CODE_FILE`, `REFRESH_DONE_YEARS`.
- `python 물환경_수질측정망.py` → 설정한 연도를 받아 `raw_data/`에 저장한 뒤 **`raw_data/`의 연도별 파일 전체**를 합쳐 `data/all_data.csv`를 만든다(설정한 연도만 합치지 않음).
- `python 물환경_수질측정망.py --merge-only` → API 호출 없이 결합만 다시 한다.
- 결합 규칙: 파일명 `YYYY.csv`·`YYYY_partial.csv`만 대상, 같은 연도에 완성본이 있으면 `_partial`은 버림, 연도마다 다른 항목 열은 합집합, 열 순서 = 지점·시점 정보 → `item*`(가나다순) → 나머지, 중복 행 제거, 지점·검사일 순 정렬.
- 실제 수집 완료(2026-11-17, 사용자 맥미니): 2024년 14,871행, 2025년 13,463행, 2026년 10,130행(~2026-09-30) → all_data 38,464행, 647개 지점(코드표 648개 중 1곳은 자료 없음).
- 요청 횟수: 648개 지점 ÷ 10개 묶음 = 연도당 65번(한 묶음 최대 466행이라 페이지 추가 없음). 공공데이터포털 개발계정 하루 한도 10,000번에 비해 아주 적다. 재시도·같은 날 반복 실행은 횟수에 더해진다.

`fetch_auto_water_quality.py`, `fetch_weis_sites.py`는 아직 가짜 응답(mock)으로만 시험했다. 첫 실행 결과(열 이름·날짜 형식)를 받으면 맞춰 고치고, 위 폴더 구조(raw_data / data / site_code)에 맞춘다.

## 3. 기본 원칙

1. **설정은 코드 맨 위**: 기간(`START_YEAR`, `END_YEAR=None`=올해), 대상(대권역·지점·항목), 파일명을 맨 위 상수로 둔다. 사용자는 거기만 고친다.
2. **경로는 코드가 있는 폴더 기준**: `BASE_DIR = Path(__file__).resolve().parent`, 그 아래 `RAW_DIR`·`DATA_DIR`·`SITE_CODE_DIR`. 단, 사용자가 "실행한 폴더"라고 하면 `Path.cwd()`.
3. **인증키는 `.env`에만**: 코드·문서·결과 파일에 키를 쓰지 않는다. `.env` 이름은 사용자가 정한 것(예: `물환경.env`)을 따르고, 변수 이름이 달라도 읽히게 한다(여러 후보 이름 → 변수가 하나면 그 값). 인코딩 키는 `unquote()`.
4. **한글 파일명은 NFC로 비교**: 맥은 파일명을 NFD로 돌려줄 수 있다. `unicodedata.normalize("NFC", name)`으로 맞춰 찾는다(폴더를 순서대로 뒤지는 `find_file(name, folders=(SITE_CODE_DIR, BASE_DIR))`).
5. **지점 목록은 `site_code/`의 CSV 코드표에서 읽는다**: 지점을 코드에 박지 않고 `물환경_수질측정망_지점코드_전체.csv`를 읽어 필터한다. 인코딩은 utf-8-sig → cp949 순으로 시도. 필요한 열이 없으면 빠진 열 이름을 알리고 멈춘다. 원본 xlsx는 더 쓰지 않는다. 자동측정망처럼 개수가 적으면 코드 안 사전으로 둬도 된다.
6. **XML로 받고 ElementTree로 읽는다**: 결과코드 `00` 확인, `03`/0건은 "자료 없음"으로 정상 처리, 게이트웨이 오류(키)는 즉시 중단.
7. **재시도·속도·횟수**: 요청 실패는 3~4회 재시도(대기 시간을 늘려 가며), 요청 사이 0.3초. 여러 지점을 한 요청에 묶어(`ptNoList` 100자 → 10개) 요청 수를 줄이고, 실행 전에 예상 요청 수를 출력한다.
8. **이어 받기**: 단위(지점×월, 또는 연도)별로 `raw_data/`에 저장하고, 다시 실행하면 받은 것은 건너뛴다. 단, 아직 공개 중인 최근 기간(자동측정망 약 3개월, 올해)은 매번 다시 받는다. 일부 실패한 단위는 `_partial`로 따로 저장해 완성본과 섞이지 않게 한다.
9. **원값 보존**: `-999`(정량한계 미만)·0·이상치는 고치지 않고 그대로 둔다. `n/a`·빈칸만 결측으로 바꾼다. 처리 방식은 열 설명에 적는다.
10. **저장 형식**: CSV는 `utf-8-sig`(엑셀에서 한글 안 깨짐). 엑셀이 필요하면 xlsx에 「자료」+「현황(기간·행수·결측률)」+「열설명」 시트. 열 이름은 API 원래 이름을 유지하고 설명표(`columns.csv`)를 따로 낸다.
11. **결합 파일**: 이번 실행분만이 아니라 `raw_data/`에 있는 단위 파일 **전체**를 합친다(따로 나눠 받은 연도가 빠지지 않게). 결합만 다시 하는 `--merge-only` 옵션을 둔다.
12. **실행 안내**: 파일 첫머리 docstring에 폴더 구성·필요 패키지·실행 명령을 쓴다. 진행 상황은 `[연도] 묶음 n/N: 건수` 식으로 짧게 출력하고, 끝에 행 수·지점 수·기간·연도별 행수를 출력한다.

## 4. 환경

- 사용자 기기: 인텔 맥(주 개발, Python 3.12, VS Code 가상환경), 맥미니(수집 폴더 위치), 윈도우 노트북. 세 곳 모두에서 돌아가야 한다.
- 패키지는 `requests pandas` 중심(엑셀 출력 시 `openpyxl`). 최신 기능이 필요한 라이브러리는 피하거나 낮은 버전으로 고정.
- `from __future__ import annotations`는 파일 맨 위에만 둘 수 있다 → 설정 상수를 맨 위에 둘 때는 쓰지 않는다(3.10+라 `Path | None` 문법은 그냥 된다).

## 5. 시험과 보고

- 사용자가 "직접 테스트하지 말라"고 하면 API를 호출하지 않는다. 대신 `requests.Session.get`을 가짜 응답으로 바꿔 끝까지 돌려 저장·결합이 되는지 확인하고, 그렇게 했다고 정확히 말한다.
- 폴더가 연결된 대화에서는 사용자 폴더 밖의 임시 폴더에서 가짜 응답 시험을 하고, 사용자 폴더에서는 API를 부르지 않는 작업(파일 이동, `--merge-only`)만 실행한다.
- 명세서와 실제가 다를 수 있는 부분(날짜 형식, 레이어 ID, JSON 구조)은 답변에 "첫 실행 후 확인할 점"으로 짧게 적는다.
- 코드표에서 확인한 사실(예: 한강 자동측정망 S01008·S01024 결번)은 코드 주석에 남긴다.
