# 수위·유량 자료 수집 개발지침

> 이 폴더의 수집 코드를 고치거나 새로 만들 때 이 문서를 먼저 읽는다. 최종 갱신 2026-11-17.
> 요청·응답 형식은 `수위_API활용가이드.md`. 공통 규칙은 `Data/수질측정망/수질자료수집_개발지침.md` 3~5절과 같다.

## 1. 목적과 위치

- `Data/` 는 주제별로 **원자료를 수집·보관**하는 곳이다. 이 폴더(`Data/수위/`)는 한강홍수통제소의 하천 수위·유량 원자료를 받는다.
- 같은 API 로 **우량계 강수량**도 함께 받는다(`GET_RAINFALL = True`). 강수량을 `Data/강수량/` 에만 모으고 싶으면 `False` 로 끄면 된다.
- 연구 분석(`연구사업/analysis_hantan_river/`)은 하천 부하 = 농도 × 유량 계산에 이 유량을 쓴다.

## 3. 수집 코드 현황

| 코드 | 대상 | 인증 | 상태 |
|---|---|---|---|
| `홍수통제소_수위유량.py` | `waterlevel`·`rainfall` 의 `list/1D`(일자료) + `info.json`(제원) | `홍수통제소.env` → `HRFCO_KEY` | 가짜 응답으로만 시험(2026-11-17). 실제 호출 전 |

### 설정(코드 맨 위)
| 이름 | 기본값 | 뜻 |
|---|---|---|
| `START_DATE` / `END_DATE` | `"2024-01-01"` / `None`(어제) | 기간 |
| `GET_WATERLEVEL` / `GET_RAINFALL` | `True` / `True` | 받을 종류 |
| `WL_CODES` | 6곳(아래 표) | 꼭 받을 수위·유량 관측소 |
| `RF_CODES` | `[]` | 꼭 받을 우량 관측소 |
| `BBOX` | `(37.80, 38.32, 126.85, 127.48)` | 이 범위(위도 최소·최대, 경도 최소·최대) 안 관측소를 제원 좌표로 자동 추가. `None` = 목록만 |
| `REFRESH_DAYS` | `60` | 이미 받은 관측소도 마지막 날짜 60일 전부터 다시 받음(실시간 자료 보정 반영) |
| `CHUNK_DAYS` | `31` | 한 번 요청 기간(일) |

### 실행
```bash
cd ~/Documents/GitHub/Study/Data/수위
python 홍수통제소_수위유량.py --test        # 관측소 1곳씩 7일, 응답 원문 앞부분과 읽은 결과
python 홍수통제소_수위유량.py --list        # 제원 저장 + BBOX 안 대상 관측소 목록
python 홍수통제소_수위유량.py               # 수집 → 결합
python 홍수통제소_수위유량.py --merge-only  # 결합만
```

### 동작 요약
- 관측소마다 `CHUNK_DAYS` 씩 나눠 요청. 실행 전에 예상 요청 수를 출력.
- 관측소별 파일에 이어 붙임(같은 날짜는 새 값으로 덮음). 파일 시작일이 `START_DATE` 보다 늦으면 처음부터 다시 받음.
- 1D 요청 날짜는 `yyyyMMdd` 로 먼저 보내고, 빈 응답이면 `yyyyMMddHHmm` 으로 자동 재시도(맞는 형식을 기억).
- 응답 열 이름은 소문자로 맞춰 읽음(`WL`/`wl` 모두). 시간 열은 `ymd` → `ymdh` → `ymdhm` 순으로 찾음.
- 위경도는 도-분-초(`127-03-25`)를 십진수로 바꿔 저장(`raw_lat`·`raw_lon` 에 원래 값 보존).
- 인증 오류는 즉시 중단. 오류 문구에서 인증키는 `<인증키>` 로 가림(주소에 키가 들어가므로).

## 4. 원칙(요약)

1. 설정은 코드 맨 위, 경로는 코드 폴더 기준.
2. 인증키는 `홍수통제소.env` 에만. 변수 이름 후보: HRFCO_KEY → HRFCO_API_KEY → SERVICE_KEY … → 변수가 하나면 그 값.
3. 한글 파일명 NFC 비교, CSV `utf-8-sig`, `requests pandas` 만 사용.
4. 원값 보존: 유량 0·음수·이상치는 고치지 않음. 빈칸·`-` 만 결측.
5. 이 API 는 **실시간(확정 전) 자료**. 논문용 확정 값은 WAMIS(국가수자원관리종합정보시스템)·수문조사연보와 대조.
